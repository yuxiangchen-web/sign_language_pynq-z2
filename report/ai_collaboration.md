# AI 协作记录

## 1. 基本信息

- 项目名称：基于 PYNQ-Z2 的手语识别系统
- AI 工具：OpenAI Codex
- 协作方式：用户负责需求确认、软件操作、硬件连接、代码运行和结果验证；AI 提供方案建议、示例代码、故障分析和文档辅助。
- 记录说明：早期条目根据聊天记录补录；从 2026 年 9 月 18 日起持续实时更新。
- 使用原则：AI 生成的内容必须经过实际运行或人工审核，不把未经验证的结果写入参赛材料。

## 2. 协作记录

### 2026-09-14 至 2026-09-16：项目规划与环境准备

- 用户目标：从零开始完成 PYNQ-Z2 手语识别参赛项目。
- AI 协助：
  - 分析项目目标并制定阶段性推进计划。
  - 建议采用“5 种静态手势 + unknown”作为最小可行系统。
  - 建议采用 PC 基线与 FPGA 加速版本进行性能对比。
  - 协助检查和安装 Vivado、Vitis、Python、OpenCV 与 NumPy。
  - 指导清理旧版 Vivado 2019.2。
- 用户操作：
  - 完成 Vivado ML Standard 2025.2 和 Vitis 2025.2 安装。
  - 建立 Python 3.11 虚拟环境并验证 OpenCV、NumPy。
- 验证结果：
  - Vivado、Vitis 和 Python 环境均可正常运行。
  - Python 图像读取与灰度处理测试通过。

### 2026-09-16：Vivado 基础硬件工程

- 用户目标：验证 PYNQ-Z2 FPGA 开发流程。
- AI 协助：
  - 指导创建 PYNQ-Z2 Vivado 工程。
  - 指导添加 ZYNQ7 Processing System、AXI GPIO、SmartConnect 和复位模块。
  - 指导地址分配、设计验证、Wrapper 创建和 Bitstream 生成。
- 用户操作：
  - 按步骤完成 Block Design 和综合实现。
  - 导出 `led_test.bit` 与 `led_test.hwh`。
- 验证结果：
  - Bitstream 成功生成。
  - 时序检查通过。
  - Vivado 重建 Tcl 脚本已导出。

### 2026-09-16 至 2026-09-18：PC 图像处理流程

- 用户目标：在板卡和摄像头暂不可用时先完成 PC 端算法验证。
- AI 协助：
  - 提供灰度转换、Otsu 二值化和形态学处理示例。
  - 提供最大轮廓检测和手部区域框选示例。
  - 根据木纹背景误识别结果，建议改用肤色分割和纯色背景。
  - 提供手部区域裁剪以及 128×128 标准化代码。
- 用户操作：
  - 运行各阶段 Python 程序。
  - 检查生成的灰度图、二值图、轮廓图和标准化手部掩膜。
- 验证结果：
  - 深色背景下能够提取较清晰的手部轮廓。
  - 成功生成 128×128 黑底白色手形图。

### 2026-09-18：特征提取与基线分类

- 用户目标：验证从输入图片到手势分类的完整软件流程。
- AI 协助：
  - 提供 HOG 特征提取程序。
  - 分析 OpenCV 5 缺少 `cv2.HOGDescriptor` 的报错。
  - 建议在项目虚拟环境中改用 OpenCV 4.14.0.94。
  - 提供批量预处理、批量 HOG 特征提取和原型分类器代码。
- 用户操作：
  - 安装并验证 OpenCV 4.14.0.94。
  - 对图片进行分类整理和批量处理。
  - 运行基线分类器。
- 验证结果：
  - 每张图片成功生成 1764 维 HOG 特征。
  - 7 个测试样本覆盖 6 个类别。
  - 训练集回测为 100%，但因样本过少，不作为最终准确率。
  - 模型保存为 `models/prototype_model.npz`。
